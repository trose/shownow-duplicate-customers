# Duplicate Customer Records Project

This is a monorepo for Salesforce and React components to handle duplicate customer records.

## Structure

- `src/salesforce/`: Salesforce-specific code (objects, classes, tests)
- `src/react/`: React components, hooks, services, types, tests
- `src/shared/`: Shared types and utilities
- `docs/`: Documentation
- `scripts/`: Utility scripts
